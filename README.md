## 🛠 روش اول: ساخت APK از GitHub (بدون نصب اندروید استودیو)

حوصلت نمی‌کشه IDE نصب کنی؟ این روش دقیقاً همون کریه 🍃

1. این پوشه رو بریز توی یه ریپوی جدید GitHub (شاخه `main`).
2. برو تب **Actions** ← **Build APK** ← **Run workflow**.
3. چند دقیقه صبر کن ⏳ بعد از بخش **Artifacts** فایل `daftar-man-apk` رو دانلود کن، zip رو باز کن و `app-debug.apk` رو روی گوشی نصب کن.
   - 🔓 یادت نره که **نصب از منابع ناشناس** رو فعال کرده باشی.

---

## 💻 روش دوم: ساخت روی سیستم خودت

اگه دوست داری همه‌چیز دست خودت باشه، این مسیر رو برو 👇

**پیش‌نیازها:** Node 18+، JDK 17 و Android SDK (یا همون Android Studio).

```bash
npm install
npm run build
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

📦 خروجی اینجاست:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

## 🏦 تشخیص پیامک بانکی (اینجا جذاب می‌شه!)

- اولین بار که اپ رو باز کردی، اندروید می‌پرسه اجازه خوندن پیامک بده یا نه؟ **«اجازه»** رو بزن ✅
- پیامک‌های بانکی خودشون میان توی بخش **«پیامک‌های بانکی»** داشبورد. روی هر کدوم بزن، دسته و توضیح بنویس، ذخیره کن 💾
- اگه مبلغ‌ها **۱۰ برابر یا ۱۰ برابر کمتر** نشون داده شدن، گزینه **«واحد مبلغ در پیامک»** رو عوض کن (چون اکثر بانک‌ها مبلغ رو به ریال می‌فرستن 🤯)
- روی هر کیف‌پول بزن و **«کد حساب در پیامک»** (مثلاً `94001`) رو وارد کن تا کارتت خودکار شناسایی بشه 🎯
- 🔒 **نکته امنیتی مهم:** پیامک‌ها فقط روی گوشی خودت پردازش می‌شن و هیچ‌جا ارسال نمی‌شن. خیالت راحت 🛡️
